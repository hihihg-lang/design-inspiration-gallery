Common Patterns Used

Each style page follows a consistent architecture to ensure familiarity and ease of navigation.

1

Consistent Page Structure

Every style page follows: Navigation → Hero → Feature Grid → Color Palette → Components (Buttons / Cards / Forms) → Style Info → Footer

2

Tailwind CSS Utility Classes

Layout, spacing, typography, and colors are handled via Tailwind utility classes for rapid development and consistency.

3

Custom CSS for Style-Specific Effects

Tailwind handles the baseline; custom CSS properties like backdrop-filter, box-shadow, and @keyframes deliver each style's signature look.

4

Responsive Grid Layouts

Tailwind responsive breakpoints (md:, lg:, xl:) ensure layouts adapt from mobile to desktop.

Style-Specific CSS Techniques

Each design style achieves its unique visual identity through a focused set of CSS properties.

Style Key CSS Properties
Minimalism grid, tracking, leading
Neumorphism box-shadow (dual), border-radius
Glassmorphism backdrop-filter: blur(), rgba()
Claymorphism box-shadow (inset+outer), border-radius
Skeuomorphism linear-gradient, box-shadow, border
Flat Design Solid colors, no shadows
Aurora UI background-size animation, radial-gradient
Brutalism border, solid colors, mono font
Neubrutalism box-shadow (hard offset), border
Bento Grid grid-template, border-radius
Cyberpunk text-shadow, filter, monospace
Vaporwave linear-gradient, @keyframes, grid
Swiss Modernism grid-template-columns, font-weight
Liquid Glass backdrop-filter, border-radius, @keyframes morph
Gen Z Chaos transform: rotate(), @keyframes, flexbox

Deployment

🐙

GitHub Pages

Push to main branch, enable Pages in repository Settings. Your site will be live at username.github.io/repo.

▲

Netlify

Drag and drop the project folder into Netlify's deploy UI. Instant HTTPS and continuous deployment from Git.

📦

Any Static Hosting

Upload all files as-is to any web server, S3 bucket, or CDN. No build step, no server-side processing needed.
