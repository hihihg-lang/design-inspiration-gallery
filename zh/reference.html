使用的通用模式

每个风格页面遵循一致的架构，确保熟悉度和导航便捷性。

1

一致的页面结构

每个风格页面遵循：导航 → 英雄区 → 功能网格 → 配色方案 → 组件（按钮/卡片/表单）→ 风格信息 → 页脚

2

Tailwind CSS 实用类

布局、间距、排版和颜色通过 Tailwind 实用类处理，实现快速开发和一致性。

3

自定义 CSS 实现风格特定效果

Tailwind 处理基础；自定义 CSS 属性如 backdrop-filter、box-shadow 和 @keyframes 实现每种风格的标志性外观。

4

响应式网格布局

Tailwind 响应式断点（md:、lg:、xl:）确保布局从移动端到桌面端自适应。

风格特定的 CSS 技巧

每种设计风格通过一组聚焦的 CSS 属性实现其独特的视觉识别。

风格 关键 CSS 属性

扁平设计 纯色，无阴影
极光 UI background-size 动画, radial-gradient
粗野主义 border, 纯色, 等宽字体
新粗野主义 box-shadow（硬偏移）, border

赛博朋克 text-shadow, filter, monospace

部署方式

🐙

GitHub Pages

推送到 main 分支，在仓库设置中启用 Pages。您的站点将在 username.github.io/repo 上线。
