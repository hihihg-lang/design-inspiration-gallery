Features

🔮

3D Depth

CSS perspective with rotateY/rotateX creates a genuine sense of 3D space, making elements feel suspended above the screen.

🪟

Glassmorphism

backdrop-blur creates frosted glass effects. Semi-transparent panels layered over gradient backgrounds create a light, airy visual hierarchy.

✨

Float Animation

Different float animation speeds give each element a unique breathing rhythm, enhancing the sense of depth and vitality.
